# Исида

Текстовая ролевая игра в киберпанке от студии Isidacorp. Мастер — Claude на подписке игрока: игра живёт как артефакт на claude.ai, кубики и правила 5e считает движок на странице.

## Разработка

```
npm install
npm test
npm run build   # dist-artifact/isida.html — страница для публикации артефактом
```
