# Исидакорп

Текстовая ролевая игра в киберпанке с ИИ-мастером на Claude. Играется в браузере телефона, ставится на экран «Домой».

Нужен свой ключ API Anthropic (console.anthropic.com). Ключ хранится только в браузере и отправляется напрямую в Anthropic.

## Разработка

```
npm install
npm run dev
npm test
npm run build
```
