# Исида — концепт

Одиночная текстовая ролевая игра в киберпанке. Мастер — нейросеть Claude, правила — 5-я редакция (SRD 5.2), мир свой.

## Решения

- Правила: 5e по SRD — характеристики, проверки d20 против КС, мастерство, преимущество/помеха, КД, хиты, инициатива, спасброски, смерть при 0 хитов. Всё считает движок.
- Контент: свои классы (Соло, Нетраннер, Техник, Медтех, Фейсер, Призрак), оружие, бестиарий; вместо заклинаний — способности класса с зарядами.
- Игрок один. Основная версия — артефакт claude.ai на подписке игрока (самая умная модель); запасная — сайт с ключом API (Opus 5.5).
- Название игры — «Исида»; Isidacorp — студия, её знак в заставке. Интерфейс по брендбуку студии.
- Мир: мегаполис Исида, 2089, корпорация «Исидакорп». Районы: Верхний Шпиль, Неоновый рынок, Ржавые доки, Пепельный квартал, Глубина (сеть).
